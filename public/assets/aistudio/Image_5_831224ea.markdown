## Brand & Style

This design system delivers a crisp, high-focus productivity aesthetic engineered for modern workflows. It targets knowledge workers, engineers, and project managers who demand uncompromising speed and clarity. The UI evokes a sense of calm efficiency, absolute precision, and unyielding focus through a restrained visual vocabulary.

The design style merges a refined **Corporate / Modern** baseline with subtle **Low-contrast outlines** and structured spatial rhythm. Surfaces are clean and deliberate, avoiding extraneous decoration to keep the user's attention anchored entirely on task execution and data comprehension.

## Colors

The palette is built for extended focus sessions, utilizing a soft cool-gray canvas that reduces eye strain against crisp white structural elements. 

- **Primary (`#0078D4`):** Microsoft Outlook blue, deployed purposefully for actionable items, interactive states, and email-sourced task indicators.
- **Secondary (`#0F172A`):** Deep slate, utilized for primary typography and high-emphasis anchors to ensure maximum legibility.
- **Neutral (`#F8FAFC`):** Soft cool-gray background canvas, establishing a calm, expansive workspace foundation.
- **Surface (`#FFFFFF`):** Pure white for cards and floating containers, lifting content cleanly off the canvas.
- **Border (`#E2E8F0`):** Subtle neutral divider tone for precise boundary definition without visual clutter.

## Typography

Typography acts as the primary vehicle for information hierarchy. Using **Inter** exclusively across all roles ensures a systematic, highly legible reading experience across dense task lists and high-level project views. 

Font sizes above 28px are avoided to maintain strict spatial efficiency on desktop displays. For mobile viewpoints, scale down headline-lg to 24px with a 32px line height. Ensure all numerical data uses tabular figures to preserve vertical alignment in lists and tables.

## Layout & Spacing

This design system employs a **Fluid grid** model structured around an 8px baseline rhythm. The workspace adapts dynamically from a single-column layout on mobile devices to a sophisticated multi-pane master-detail view on desktop.

- **Mobile (< 768px):** Single-column stack with 16px canvas margins and collapsed navigation drawers.
- **Tablet (768px – 1024px):** Two-pane layout with a collapsible sidebar and flexible content canvas, utilizing 20px gutters.
